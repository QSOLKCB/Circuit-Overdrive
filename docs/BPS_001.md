# BPS-001 — Bounded Phrase Sequencer

**Status:** standalone implementation review candidate, not yet connected to Circuit Overdrive's runtime audio. Owner acceptance, the course compositions and browser integration are separate PRs.

`src/bps.js` compiles at most eight 16-step phrases into a privately owned, sample-indexed **48 kHz stereo PCM16** loop. The pure compiler has no ambient clock, `Math.random`, DOM, AudioContext, network or runtime package dependencies.

Each phrase contains `bass`, `lead` and `arp` arrays of sixteen MIDI note integers (24–96) or `null` rests, plus sixteen percussion symbols: `K` kick, `S` snare, `H` hat, `.` rest. The score has a compact ID, genre mode, integer BPM and uint32 seed. BPM must make sixteenth-note durations an exact integer number of PCM sample frames; e.g. 120, 144, 150 and 180 are valid. Maximum loop length is 48 seconds.

Example:

```js
import {createBoundedPhraseSequencer} from './src/bps.js';
const phrase={
  bass:[45,null,null,null,43,null,null,null,41,null,null,null,43,null,null,null],
  lead:[69,null,72,null,76,null,72,null,69,null,67,null,64,null,67,null],
  arp:[57,64,69,64,55,62,67,62,53,60,65,60,55,62,67,62],
  drums:['K','H','H','H','S','H','K','H','K','H','H','H','S','H','K','H']
};
const bps=createBoundedPhraseSequencer({id:'neon-demo',bpm:120,mode:'synthwave',seed:27,phrases:[phrase]});
const pcm=bps.renderRange(0,3072); // interleaved Int16 L/R
const wav=bps.wavLoop();
```

All note and effect synthesis is performed exactly once during compilation. Playback obtains slices of the cached PCM using absolute output-frame indices; chunk partitions and wraparound produce identical samples in the same JS runtime. End-of-phrase two-millisecond envelopes reduce hard boundary discontinuities. Actual click perception requires listening tests. No low-latency AudioWorklet, musical layering over arbitrary tempo, 3D spatial audio or physical chip emulation is claimed. Compilation is bounded but is not yet measured on mobile hardware.

SID-style ADSR, four-channel Paula-style PCM, and `soundtrack` in the pinned VANILLAJS engine informed the design, but this pure preparatory module introduces **no vendored engine change**. The next PR must review adoption of the existing `chip-audio` interfaces (including their limits and attribution), preserve the game's engine pin, and connect the BPS output to a gesture-owned audio bus without impacting vehicle-audio resource limits.

Verification: `node --test tests/bps.test.mjs`. Full repository and GitHub Pages checks are required before acceptance. Byte-accurate offline WAV exports and gameplay integration belong to follow-up reviews.
