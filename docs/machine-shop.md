# CO-014E — The Machine Shop

Select an occupied bay in After Hours Motor Works. **The Machine Shop** identifies the model, exact owned ID, current credits, build rules and garage revision. Nine named sections expose engine, intake, exhaust, gearbox, final drive, tyres, suspension, steering and paint. Installed parts and inventory belong to this particular car, including when two cars share a model.

Each section shows accepted and proposed specifications in the pinned solver's units. Torque curves are Nm at stated RPM, gearing is a ratio, suspension uses N/m and Ns/m, steering uses radians and rad/s. Quadratic drag is kg/m. These are compiler fields, not invented acceleration or horsepower measurements. The proposed part and quantized setup are compiled before fitting review; unsupported combinations disclose the compiler rejection. Affordability and acquisition/fitting costs come from the existing pure installation transaction, with the actual confirmation and whole-state write still owned by the Save Vault. Preview never mutates the garage. Paint is cosmetic.

Original tyre-pack rim colours and patterns correspond to the fitted tyre ID; the flow-exhaust pack adds original bounded tail pieces. These appearance changes have no separate physics effect: the existing compiled tyre/exhaust fields own the mechanical changes. Radius, track and wheelbase remain the accepted physical dimensions. In the Proving Grounds and replay viewer, actual suspension/body movement, steering and wheel hubs determine stance. Showroom rims and exhaust follow the accepted saved configuration, never the proposed selector. The renderer retains six base models plus at most eighteen variants and evicts invisible variants, preserving the 149-mesh bound across repeated fitting and inspection.

Every supported condition is pristine. The shop shows **No repairs required.** It charges no repair bill and supplies no repair transaction. Persistent damage remains deferred until an accepted impact-energy adapter exists; no benchmark or unrelated demolition match invents owned-car damage.

## Measure, compare and return

Use **Drive at the Proving Grounds**, choose a measured test, Load and arm. The actual saved build drives; stock and proposed configurations are free simulations. **Run reference comparisons** measures stock/current/proposed builds and retains their verified v7 command recordings in temporary per-tab session storage. A live finished run can also be recorded. **Finish this run** stops a manual run honestly: practice completes as stopped practice, while an interrupted benchmark is a non-completion.

Back in the shop, **Verify measured tests** re-simulates those recordings before showing its four-row comparison table. Every value has source, track/rules, build/recipe digest, tick and driving-policy provenance. No illustrative numbers appear before a test. The stock column must reconstruct the original stock build. A result recorded before a subsequent fitting is marked **Original build**, rather than silently attributed to the new configuration. Reference acceleration uses identical full-throttle tapes; other feedback policies and manual driving may use different commands, explicitly disclosed.

The temporary evidence slot is `circuit-overdrive.workshop-evidence.v1`, bounded to twelve recordings and 4 MiB UTF-8. It is untrusted and independently revalidated. It is neither ownership nor a second active garage save. There is no multi-key atomicity claim: evidence retention can fail without affecting a purchase or an accepted physical result. Storage errors are reported. The 64 KiB garage import/export and coordinated Vault envelope are unchanged. Garage exports preserve builds and inventory, not this disposable evidence cache. Keep downloaded v7 recordings to preserve tests independently of the current garage and tab.

Changing cars, accepted saves, or storage availability cancels pending verification; a stale continuation cannot publish measurements or re-enable controls after a conflict. Existing confirmation, stale-tab rejection, reload, import/export, controller navigation, touch and WebGL recovery remain in use. Saved modifications survive those operations because only accepted whole-state Garage builds supply owned-car admission.

## Watch the original build

From a finished proving run choose **Save build-bound recording · v7**, then open **Watch a proving recording**. The dedicated local `proving-replay.html` viewer admits the exact game source, reconstructs the recorded build and command stream, and verifies its terminal result before displaying a ready recording. Play/Pause, Restart, accepted-tick seeking and chase/high cameras work without the live garage. Keyboard, native touch controls and saved controller mappings operate the viewer; focus, hidden tabs and context loss pause playback.

The dedicated viewer avoids adding owned-build authority to historical Replay Theatre v2–v6. It does not reinterpret those formats or accept them as v7. See [v7 contract](proving-replay.md), [test rules](proving-ground.md), [parts and prices](vehicle-parts.md), and [save migration](garage-build-registry.md). Native GPU/endurance certification and final release remain CO-014F owner-review work.
